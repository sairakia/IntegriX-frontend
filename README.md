# IntegriX Frontend

IntegriX 프론트엔드 프로젝트입니다.

텍스트, 이미지, URL 분석 기능을 제공하는 AI 기반 통합 보안 분석 플랫폼의 사용자 화면을 담당합니다.

## 주요 기능

- 회원가입 및 로그인 화면
- 이메일 인증 UI
- URL 분석 화면
- 텍스트 분석 화면
- 이미지 분석 화면
- 마이페이지
- 분석 이력 조회
- 대시보드 통계 시각화
- 신고 피드백 화면

## 기술 스택

- React
- TypeScript
- Vite
- Tailwind CSS
- Axios
- React Router
- Recharts
- Radix UI
- Lucide React

## 프로젝트 구조

- `src/app/components/pages` : 주요 페이지 컴포넌트
- `src/app/components/ui` : 공통 UI 컴포넌트
- `src/app/contexts` : 인증 상태 관리
- `src/app/api` : API 설정 및 토큰 관련 유틸
- `src/assets` : 이미지 리소스
