Create a clean and modern web dashboard UI for a platform called
“Online Content Trust Analysis Platform”.

The platform has two main features:

1. Website Risk Analysis (URL-based)
2. Content Fact-Check Analysis (text/news-based)

Design should be clean, minimal, and professional (similar to fintech/security dashboard).

---

## 🧩 Overall Layout

* Top navigation bar:

  * Logo (left)
  * Menu: Dashboard / Website Analysis / Content Analysis / History / Report
  * User profile icon (right)

* Left sidebar (optional modern layout):

  * Dashboard
  * Website Risk Analysis
  * Content Fact Check
  * Analysis History
  * Report / Feedback

---

## 📊 1. Dashboard Page

Purpose: Overview only (NO input forms here)

Include:

* Summary cards:

  * Total analyses count
  * Risky websites detected
  * Suspicious content detected
* Charts:

  * Pie chart (Safe / Caution / Dangerous ratio)
  * Line chart (analysis trend over time)
* Recent activity list:

  * Recent analyzed URLs and content
  * Status badges (Safe / Caution / Danger)

---

## 🌐 2. Website Risk Analysis Page

Purpose: Analyze URL safety BEFORE visiting

UI Components:

* Large URL input box (centered)
* “Analyze” button

Result section (after input):

* Risk level badge:

  * Safe (green)
  * Caution (yellow)
  * Dangerous (red)
* Risk score (0–100)
* Detected issues list:

  * Suspicious keywords
  * Domain anomaly
  * Possible phishing pattern
* Simple visual indicator (progress bar or gauge)

---

## 📰 3. Content Fact-Check Page

Purpose: Analyze credibility of text/news content

UI Components:

* Large text input area
* Optional: URL input for news article
* “Analyze Content” button

Result section:

* Credibility level:

  * Reliable / Needs Verification / Suspicious
* AI summary:

  * Key claims extracted
  * Risky expressions (exaggeration, misleading tone)
* Highlighted text:

  * Problematic sentences marked

---

## 🧾 4. Analysis History Page

* Table layout:

  * Type (URL / Content)
  * Input (URL or text snippet)
  * Result (Safe / Danger etc.)
  * Date
* Filter options:

  * By type
  * By result

---

## 🚨 5. Report Page

* Report suspicious URL or content
* Input form:

  * URL or text
  * Reason
* Submit button

---

## 🎨 Design Style

* Clean, modern UI (like admin dashboard)
* Soft shadows, rounded cards
* Color system:

  * Green = Safe
  * Yellow = Caution
  * Red = Dangerous
* Use icons for clarity (shield, warning, search, etc.)

---

## 📱 Additional Notes

* Keep Website Analysis and Content Analysis COMPLETELY SEPARATED
* Dashboard is only for visualization, NOT analysis input
* Focus on usability and clarity
